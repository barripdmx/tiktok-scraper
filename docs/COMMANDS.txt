📊 ESTADOS DE SALIDA
════════════════════════════════════════════════════════════════════════════

   ✅ Exitoso             → Comentarios descargados (cobertura 70%+)
   ⚠️  Exitoso (bajo)      → Comentarios descargados (cobertura <70%)
   🚫 Deshabilitados      → Video tiene comentarios cerrados (definitivo)
   ❌ Panel error         → Botón no encontrado / UI rota (definitivo)
   ⏱ Sin respuesta        → API silenciosa >50s (transitorio)

     data/logs/comentarios_api_*.log      ← 📝 Logs de ejecución

🔧 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

   ❓ "Cookies no cargadas"
   → python 1-guardar_sesion.py

   ❓ "Panel no encontrado" en varios videos
   → python 1-guardar_sesion.py
   → Reinicia la sesión

   ❓ Muchos videos con "🚫 Deshabilitados"
   → Normal: algunos creadores cierran comentarios
   → Revisa el resumen final para estadísticas

   ❓ Quiero continuar desde donde quedó
   → python scraper.py data/usuarios.csv
   → Responde "S" cuando pregunte
